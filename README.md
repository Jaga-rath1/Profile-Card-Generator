# Profile Card Generator

A simple and interactive web application that allows users to create profile cards dynamically using form input. This project is built using pure JavaScript DOM manipulation.

## 🚀 Features

* Create profile cards with image, name, occupation, and description
* Real-time DOM manipulation
* Clean and responsive UI
* Hover animations for better user experience

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript (DOM)

## 📸 How It Works

1. Enter your profile image URL
2. Fill in your name, occupation, and description
3. Click submit
4. A new profile card will be generated instantly

## 💡 Future Improvements

* Add delete button for cards
* Edit existing cards
* Save data using Local Storage
* Add animations using GSAP
